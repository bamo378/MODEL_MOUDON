# Model SA, Moudon – simulateur PV + batterie

Page web statique (aucune installation) qui compare les variantes V1, V2 et V3 :
simulation au quart d'heure sur la courbe de charge réelle (01.10.2025 → 30.09.2026),
peak shaving, autoconsommation, subventions RU/RUE et flux financiers type Soleol.

**Ouvrir :** télécharger le dépôt puis ouvrir `index.html` dans un navigateur
(ou activer GitHub Pages sur la branche `main`).

- `index.html`, `style.css`, `app.js` : l'application
- `data.js` : courbe de charge et profil de production
- Paramètres par défaut : fichiers « Flux Inv. propre » V1–V3, fichier vert, factures Romande Energie
